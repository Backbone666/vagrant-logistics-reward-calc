# vagrant-logistics-reward-calc

A Shipping Contract Reward Calculator for Eve Online's Vagrant Logistics corporation.

## Installation

1. Clone the repository:
```bash
git clone https://github.com/backbone666/vagrant-logistics-reward-calc.git
```

2. Open the `index.html` file in your web browser.

## Usage

1. Enter the collateral amount in ISK.
2. Enter the number of jumps.
3. Enter the volume of the cargo in cubic meters.
4. Check the "Low / Nullsec / Dangerous Space" box if the route is in low or nullsec.
5. Click the "Calculate" button to see the estimated reward.
